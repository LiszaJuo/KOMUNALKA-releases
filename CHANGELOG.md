# История версий

Кратко, одним взглядом. Подробности и файлы сборок — на вкладке [Releases](https://github.com/LiszaJuo/KOMUNALKA-releases/releases).

## 0.2.12

- Из коробки: проверка при запуске и канал GitHub с адресом публичных сборок включены; запасной канал выключен

## 0.2.11

- Канал GitHub: адрес релизов задаётся в настройках на этом ПК
- Экран обновлений: понятнее каналы, статусы и действия

## 0.2.10

Первая публичная сборка.

- Записная книжка для учёта коммунальных платежей (Windows, в браузере)
- Лицевые счета и счётчики, документы (сканы, фото, PDF)
- Автосохранение; архив-копия вручную; копия данных перед обновлением
