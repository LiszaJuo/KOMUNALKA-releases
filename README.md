# KOMMUNALKA

Некоммерческая, простая программулька — записная книжка для учёта коммунальных платежей.

В этом репозитории — **готовые сборки** для установки и обновления (ZIP и setup.exe).

- **Платформа:** Windows  
- **Интерфейс:** обычный браузер (Chrome, Edge и т.п.)  
- **Режим:** портативная, автономная — интернет не нужен; только для автообновления, если его включить

## Что умеет

- Лицевые счета и счётчики: свет, квартплата (ЕПД), газ, вода, интернет, телефон, собственность, налоги
- Документы (сканы и PDF) рядом с данными
- Копии данных и обновление без потери папки `data`

## Скачать

Откройте [Releases](https://github.com/LiszaJuo/KOMUNALKA-releases/releases) и возьмите нужную версию:

| Файл | Как пользоваться |
|------|------------------|
| `*-portable.zip` | Распаковать куда угодно → `KOMUNALKA.exe` |
| `*-setup.exe` | Указать папку установки |

Аккаунт GitHub для скачивания **не нужен**.

## Обновление

В программе: **Настройки → Обновления**. При новой версии — **Обновить**.  
Папка `data` (показания, документы, настройки) при обновлении **не затирается**.

Запасной канал — общая папка в локальной сети (если так настроено на компьютере).
