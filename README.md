# KOMUNALKA — готовые сборки

Здесь только **установочные файлы** (ZIP и setup.exe).  
Исходный код и внутренняя разработка — в отдельном private-репозитории.

## Скачать

Откройте [Releases](https://github.com/LiszaJuo/KOMUNALKA-releases/releases) и возьмите:

- **portable.zip** — распаковать куда угодно, запустить `KOMUNALKA.exe`
- **setup.exe** — указать папку установки

Аккаунт GitHub для скачивания **не нужен**.

## Обновления

Программа сама проверяет этот репозиторий (последний релиз). Личные данные на компьютере при обновлении не затираются.
